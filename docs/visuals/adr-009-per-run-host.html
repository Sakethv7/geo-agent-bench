ADR-009: one run, one host name

Read from the top. Diamonds are questions. Every failure path ends in a red box. A new host name is a new URL, so the vendor cache cannot answer.

Exists today New or changed by this ADR Failure path

The health check catches a missing wildcard DNS record or a failed certificate before the agent starts. A failed or refused run is kept in the data, and its requests still match by token. A request whose token is in no run record is a stray request. Today, matching uses only a time window.
