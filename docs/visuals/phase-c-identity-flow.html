Phase C: one request through the signature check and the sign-in (ADR-021 to ADR-023)

Read from the top. Diamonds are questions. Each failure path ends in a red box. Two separate checks run: who is the client, and what may it read.

exists todaynew or changedfailure path

The signature check never changes the status code. It only writes a verdict, so a spoofer can still get a public page. The token check is separate. It decides who may read the orders. A spoofed agent that holds a valid token still gets the orders page, because identity and permission are two different checks. The sign-in steps run in our harness. The model never holds a key or a token. If the user says no, no token exists and the model only sees a 401.
